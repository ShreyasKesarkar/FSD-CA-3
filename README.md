# Clinic Queue Management - CA3

This workspace contains five independent programs matching the five questions:

1. `01-browser-queue` - HTML/CSS/JavaScript DOM, events, Fetch API, search and filtering.
2. `02-react-queue` - React components, props, state, effects and React Router.
3. `03-node-utility` - Node HTTP server using `fs`, `path`, streams and EventEmitter.
4. `04-express-api` - Express CRUD API, middleware, JWT authentication and bcrypt.
5. `05-integrated-app` - React + Express + PostgreSQL/Sequelize integration with deployment notes.

Each folder contains its own `question.md`. Run `npm install` inside a folder containing `package.json` before starting it.
